# Wireless Lab (nrtrail) — 무선 신호를 보고, 따라가고, 실험하는 로컬 도구

**한국어** · [English](README.en.md)

SDR 장비, 컴퓨터의 Wi-Fi·블루투스, 저장된 파일의 신호를 웹 화면에서 클릭으로 다루고,
무슨 일이 일어났는지를 그림과 수식으로 보여주는 로컬 도구입니다. 브라우저 ↔ 내 컴퓨터의 서버(`127.0.0.1`)로만 동작합니다.

기지국(5G NR), Wi-Fi, 블루투스를 한 곳에서 다루는 것이 목표입니다. 프로그램을 열면 쓸 장비를 고르고 **수신** 또는 **송신**을 누릅니다. 장비가 여러 대면 장비마다 책갈피가 생기고, "전체 보기"에서 모든 장비의 결과를 나란히 봅니다.

## 할 수 있는 일

- **5G NR 기지국 따라가기** (NTN 포함): 스캔 → SSB → MIB → SIB1 → SIB19 순서로 진행합니다. 화면의 값마다 "원시값 → 공식 → 결과 → 표준 조항"을 펼쳐 볼 수 있습니다.
- **수신**: 대역과 채널을 고르거나 가운데 주파수와 대역폭을 직접 적어 그 대역을 봅니다. 자주 보는 주파수는 추가해 둘 수 있습니다.
- **실시간 보기** (Pro): 멈출 때까지 끊김 없이 받으면서 스펙트럼과 스펙트로그램을 초당 20번 그립니다. 지금 보이는 신호의 종류를 폭과 대역으로 추정해 표시하고, 실제로 푼 것은 따로 표시합니다. 받는 도중에 녹화 단추로 I/Q 를 파일(SigMF)로 남깁니다.
- **신호 분석**: 녹화해 둔 I/Q 파일(SigMF, .cfile, .cs16)을 열어 뜯어봅니다. 파일 전체를 훑어 켜졌다 꺼지는 신호(버스트)를 찾고, 구간마다 스펙트로그램·스펙트럼·시간 파형·순간 주파수·성상도를 그립니다. 신호 하나를 골라 가운데 주파수, 차지한 폭, 변조 방식(추정)을 잽니다. 장비 없이 됩니다.
- **채널별 세기 비교**: Wi-Fi 2.4 / 5 / 6 GHz 와 블루투스 채널의 세기를 돌아가며 재서 비교합니다.
- **Wi-Fi**: Pro 에서는 주변 AP 와 프레임 종류·대역폭까지 풉니다.
- **블루투스**: BLE 광고(누구나 받으라고 내보내는 방송)를 받아 풉니다.
- **주변 보기**: SDR 이 없어도 컴퓨터의 Wi-Fi·블루투스로 주변 망의 채널·세기와 주변 기기의 광고를 봅니다(연결하지 않음).
- **실험용 송신** (Pro): 시험 톤, 표준 시험 신호, 직접 만든 파형을 내보내고, 보내면서 받아 실제로 나갔는지 확인합니다. 장비 여러 대를 같은 시각에 함께 시작할 수 있습니다.
- **여러 장비 함께 쓰기**: 한 대로 보내면서 다른 대로 받는 식으로, 장비마다 따로 설정하고 한 번에 시작·정지합니다.
- **연습 모드**: 저장된 결과를 재생하므로 장비 없이 전 과정을 체험할 수 있습니다.

이 공개판(Basic)은 **수신만** 합니다.

## 장비

| 종류 | 예 | 할 수 있는 일 |
|---|---|---|
| 꽂는 장비 (SDR) | USRP B·N·X 계열과 E320 (Pro, 꽂으면 자동 등록), SoapySDR 장비 | 기지국 따라가기, 수신, 실시간 보기(Pro), 채널별 세기 비교, 블루투스 수신, 송신(Pro) |
| 컴퓨터의 Wi-Fi 어댑터 (내장·외장) | 노트북 내장 Wi-Fi, USB 랜카드 | 주변 망의 채널·폭·세기 |
| 컴퓨터의 블루투스 어댑터 (내장·외장) | 내장 블루투스, USB 동글 | 주변 기기의 광고(이름, 제조사, 세기) |
| 장비 없음 | — | 연습 모드, 저장 파일 열기 |

## 이 저장소에 들어 있는 것

- `web/` 화면 (React + TypeScript + Vite)
- `server/` 로컬 서버 (FastAPI): 세션, 작업, 장비 계층, ASN.1 해석, 표준 표 풀이, 위성 계산, 채널별 세기 비교, BLE 수신, 신호 종류 추정
- `pipeline/` 단계 정의와 문구, 연습 모드가 재생하는 저장된 결과
- `tools/` 환경 점검, 실행, 전체 검증

Basic 에서 실제 장비를 쓰려면 SoapySDR 과 장비 모듈을 따로 설치해야 합니다(없어도 연습 모드는 됩니다).

## 실행

```
python3.12 -m venv venv
venv/bin/pip install -e '.[dev]'
cd web && npm install && npm run build && cd ..
venv/bin/python tools/doctor.py          # 환경 점검
venv/bin/python tools/dev.py --built     # http://127.0.0.1:8765
```

프로그램처럼 쓰려면 아래를 더블클릭합니다. 가상환경이 없으면 처음 한 번 스스로 만들고 필요한 파이썬 패키지를 깝니다(`tools/bootstrap.py`. 화면을 지으려면 Node.js 가 있어야 합니다). 서버를 띄우고 창을 열며, 창을 닫으면 전부 꺼집니다.

| 운영체제 | 실행 파일 |
|---|---|
| macOS | `Wireless Lab.app` (창만 뜹니다) 또는 `nrtrail.command` (터미널 창이 함께 열립니다. 처음 한 번 폴더 접근 허용을 물을 수 있습니다) |
| Windows | `nrtrail.bat` |
| Linux | `./nrtrail.sh` |

Windows에서는 `venv\Scripts\python`으로 바꿔 씁니다. 전체 검증은 `venv/bin/python tools/verify.py`.

## 하지 않는 것

- 이 공개판에는 송신(TX) 코드가 없습니다. 어떤 SDR API 의 송신 경로도 호출하지 않습니다. (화면의 "송신" 타일은 Pro 가 있을 때만 켜집니다.)
- 재밍, 스푸핑, 위조 기지국 기능은 어느 판에도 없습니다.
- 서버는 `127.0.0.1`에서만 열립니다.
- 실시간 장비 입력으로는 방송 정보(기지국의 SSB·MIB·SIB, Wi-Fi 비콘과 프레임 머리말, BLE 광고)까지만 처리합니다. 개별 기기끼리 주고받는 내용은 풀지 않습니다.

## 지원 환경

macOS 에서 개발하고 시험합니다. Windows 와 Linux 는 준비 중입니다.
